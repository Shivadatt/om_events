Developer reference

Om Events REST API

JSON endpoints are same-origin, rate-limited, and return conventional HTTP status codes. Admin endpoints require Authorization: Bearer <token>.

Public catalog

GET /api/categoriesGET /api/items?q=&category=&sort=&page=GET /api/items/{slug}GET /api/reviews

Customer actions

POST /api/leadsPOST /api/quotesGET /api/quotes/{public_id}/pdf

Administration

POST /api/auth/loginGET /api/auth/meGET /api/admin/stats

See postman/Om-Events.postman_collection.json for request bodies and examples.
